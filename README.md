# Limbus Assistant

『Limbus Company』の非公式攻略データベース。人格・E.G.O・編成・ボス攻略・用語をまとめて調べられる。

**サイト: https://limbus-assistant.com/**

スマホ・PC どちらのブラウザでも見られる。登録やインストールは不要。

## できること

| ページ | 内容 |
|---|---|
| [リセマラ](https://limbus-assistant.com/reroll) | 始める前に。おすすめ人格と、どこで終えてよいかの目安 |
| [初心者ガイド](https://limbus-assistant.com/beginner) | ストーリーの進め方から、育成・日課・交換までを順番に案内する |
| [編成例](https://limbus-assistant.com/teams) | 火傷・出血・破裂など、キーワードごとの組み方と人格の役割 |
| [ボス攻略](https://limbus-assistant.com/bosses) | 詰まりやすい戦闘の負け方と対処、敵のスキル・パッシブ |
| [用語辞典](https://limbus-assistant.com/glossary) | 状態異常・バトルの仕組みなど、共通用語の解説 |
| [キーワード別人格一覧](https://limbus-assistant.com/keywords) | 火傷・出血・破裂など、キーワードを持つ人格を囚人ごとに一覧 |
| 囚人・人格・E.G.O | 囚人ごとの人格と E.G.O の一覧。スキル・パッシブ・耐性などのデータと、使い方の解説 |
| [サイト内検索](https://limbus-assistant.com/search) | 人格名・囚人名・ボス名・用語からまとめて探せる |

## 表記について

- 囚人・人格・スキルなどの名前は**日本語版**の表記にそろえている。
- 用語は [LimbusCompany攻略Wiki](https://wikiwiki.jp/lcbwiki/) の日本語表記に合わせている。

## 注意

- 本サイトは非公式のファンサイトで、Project Moon とは関係ない。
- データは LimbusCompany攻略Wiki をもとにしている。ゲームのアップデート直後は、反映が遅れることがある。
- 誤りや反映漏れに気づいたら、[Issues](https://github.com/u-lquiorra/limbus-assistant/issues) から知らせてもらえると助かる。
