# 日英表示

日本語版は従来のURL、英語版は `/en/` 配下で配信する。言語切替は同じページ・クエリ・節を保つ。各言語を静的HTMLに生成し、言語属性・canonical・hreflang・構造化データを設定する。

未訳は日本語のまま表示する。英語版も検索エンジンに登録し、サイトマップへ含める。登録しないページ(検索結果・見つからないページなど)は日本語版と同じ扱いにする。各ページは `hreflang` で日英の対応を示し、`x-default` は日本語版を指す。

囚人ページの英語版は英語のスラッグで配信する(`/en/character/yi-sang`)。日本語版の URL(`/character/イサン`)は変えない。対応は `path.ts` の `SINNER_SLUGS` にあり、`languagePath` と `originalPath` が変換する。

優先範囲は上部メニューの一覧・案内ページ（トップ、編成例、初心者、リセマラ、ボス一覧、用語辞典）。用語辞典は48項目の詳細・補足項目・図解・注意点・関連検索語まで直接英訳を持つ。日本語の読み仮名は日本語版で表示し、英語版では英語の関連語を表示する。

## 直接英訳の更新

`direct/*.json` に原文と英訳を保存し、次を実行する。外部の翻訳サービスへは接続しない。通常のビルドでも同じ統合処理を行う。

```sh
npm run i18n:compile
```

直接英訳は既存の下訳より優先する。攻略本文はインライン要素を連結した段落単位で翻訳し、英訳側のMarkdownから強調とリンクを復元する。原文の見出しやデータ選択条件は変更しない。

攻略原文の全段落に対応する英訳と、人格・E.G.Oへのリンク先を統合時に照合する。原文が更新されて対応する段落がなくなった場合や、リンク先が異なる場合はビルドを止める。`sourceGuide` と `code` で対象を記録し、人格の `persona-0101.json` とE.G.Oの `ego-0101.json` を区別する。

リセマラ候補は人格コードから原文へ対応づける。原文ファイルの改行をLFに正規化したSHA256を照合し、変更があればビルドを止める。再確認後に英訳とハッシュを更新する。固有名詞の出典は `src/data/localization/README.md` に記録する。

- `messages.en.json`: 統合済みの表示文と固有名詞。以前取得した機械翻訳も一部含む。
- `overrides.en.json`: 共通の訳語修正。
- `direct/*.json`: 直接英訳。数値・条件・リンクを原文と照合して追加する。
- `direct/glossary-0*.json`: 用語IDごとの本文と関連検索語。原文の表示フィールドをハッシュで照合し、本文・補足・図解の対応漏れを検出する。図の値やIDは原文データをそのまま使う。
- `provenance.en.json`: 生成元と統合状況。旧下訳の `pending` は旧収集単位の値であり、ページの翻訳完了数ではない。

表示文字列はJSXの描画時に `LanguageContext` に応じて翻訳する。フォームの値・ゲームコード・URL・アンカーIDは変えない。翻訳をHTMLとして挿入せず、Reactの文字列として描画する。

## 未訳の確認

```sh
node --import tsx scripts/audit-english.ts
# 主要ページ・辞典48項目・検索とページ送りの代表状態で未訳の残存を検査
node --import tsx scripts/audit-english.ts --navigation --check
```

英語ページを描画して実際に使われた訳を照合する。ページ別の未訳を `.cache/english/untranslated-direct.json` に保存する。翻訳対象の収集だけを行う場合は `scripts/collect-english-text.ts` を使う。いずれも公開ページだけを対象とし、外部へ送信しない。

`--navigation` は `.cache/english/navigation-audit.json` と `navigation-progress.en.json` に結果を保存する。`remainingRenderedStrings` は実際の表示文・属性・メタデータに残る日本語を数える。全体検査の候補数には、検索対象の日本語の読みや別名など、画面には出さない文字列も含む。公式英語名に含まれる漢字と「日本語」への言語切替は未訳に数えない。

`scripts/translate-english.ts` は以前の外部翻訳用ツールであり、直接英訳では使わない。外部送信を再開する場合は、変更後の送信対象について承認を得る必要がある。
