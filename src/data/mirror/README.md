# 鏡ダンジョンのデータ

`scripts/mirror.ts`(`npm run mirror`)が wiki(wikiwiki.jp/lcbwiki)から生成する。手で編集しない。

| ファイル | 取得元のページ | 中身 |
| --- | --- | --- |
| `gifts.json` | 鏡ダンジョン/E.G.Oギフト | 全 E.G.Oギフトの番号・ID・名前・罪悪属性・ランク・価格・強化費・効果・獲得イベント・分類 |
| `packs.json` | 鏡ダンジョン/各種パック獲得可能ギフト一覧 | テーマパックごとの出現ギフト(グループ共通)と限定ギフト・属性別ギフト |
| `fusions.json` | 鏡ダンジョン/E.G.Oギフト/簡易合成ギフト一覧 | 合成レシピ(素材 → 結果) |

型は `src/types.ts` の `MirrorGift` / `MirrorPack` / `MirrorFusion`。

## 読み方

- ギフトの `id` は wiki の画像ファイル名。パック・合成の表との照合に使う。一覧のアンカー名は綴りが揺れるので使わない。
- 効果文の強化段階は `〘+:…〙` / `〘++:…〙` で示す。wiki の「3/4/5」(無印/+/++)表記はそのまま残る。
- `price` が数字でないギフト(合成専用・売却不可など)は `null` にし、表記を `priceNote` に残す。
- `limitedGifts` が `null` のパックは、wiki に限定ギフトがまだ載っていない(EXTREME限定パック・新しいパックなど)。`[]` は「なし」と明記されている。
- 素材が「欠片シリーズの内1個」のような、特定のギフトでない合成レシピは含めない(実行時に警告を出す)。

## 参考ページ

攻略を書くときに読むページ(星の加護・苦難・出現敵・攻略編成・イベントなど)は `.cache/mirror/` に HTML で保存するだけで、JSON にはしない。
MD8(シーシュポスの鏡)は MD7(名と蜘蛛の鏡)から仕様の変更が無く、wiki でも出現敵・攻略編成は MD7 のページを参照しているので、MD7 のページも取得する。

## 更新

```
npm run mirror -- --refresh   # wiki から取り直す(12秒間隔、15ページで約3分)
npm run mirror                # .cache/mirror/ の HTML から作り直す
```
