# Limbus Company バトルシステム参照

攻略ガイドを書くときの前提知識。LimbusCompany攻略Wiki の「戦闘指南」配下(下記「出典」)を 2026-10-17 に読んで要約したもの。
**wiki の文章の転載ではなく要約**。仕様の細部や最新の変更は出典ページで確認すること。人格固有の数値・効果は必ず `src/data/` を正とする。

---

## 1. 基本単位

- 1人の囚人 = 人格1つ + E.G.O(最大5つ。ZAYIN/TETH/HE/WAW/ALEPH から各1)。戦闘中の味方は人格で呼ぶことが多い。
- 戦闘は **通常戦闘**(雑魚戦。マッチ相手を指定できない)と **集中戦闘**(ボス・幻想体戦。敵のスロットに自分のスキルを繋いでマッチ相手を指定する)の2形式。
- 行動はすべてスキル。スキルを使う = コインを投げる。通常攻撃は無い。
- 1ターンの流れ: 行動の指示 → 戦闘開始 → マッチ / 一方攻撃 / 守備が順に処理 → ターン終了。プレイヤーが触れるのは指示だけ。

## 2. スキルの構成と巡り

- 人格は原則 **攻撃スキル3種 + 守備スキル1種**。攻撃スキルは S1×3枚・S2×2枚・S3×1枚 の **6枚1セット** で、ランダムな順にパネルへ供給される。セットを使い切るまで同じスキルは戻らない。
  - S3 は **同期化Ⅲ** で解放(Ⅲ未満は S1×3 + S2×2 の5枚)。パッシブは同期化Ⅱで解放。
  - そのため「S3 を序盤に使い切ると強敵の大技に当てるスキルが無い」ということが起こる。弱い攻撃には S1 を当てて S3 を温存する判断が重要。
- 守備スキルと E.G.O はパネル下段の攻撃スキルを **変換して** いつでも使える(巡りに縛られない緊急手段)。
- 一部の人格は条件付きでスキルが変化する(例: 条件を満たすと S3 が別スキルとして発動)。データでは `special: true` のスキル。

## 3. 威力とコイン

- スキルの数値: **基本威力 / コイン威力 / コイン枚数 / スキルレベル(攻撃レベル) / 攻撃加重値**。
- 最終威力 = 基本威力 + コイン威力 × 表が出た枚数。表記「3-11」は全裏〜全表の範囲。
- **精神力が高いほど表が出やすい**。精神力管理がそのままスキルの強さになる。
- **減算コイン**(コイン威力がマイナス)は表が出ると威力が下がる。つまり精神力が高いほど弱くなる。
- 威力補正の効き方:

| 補正 | マッチ | 攻撃 |
|---|---|---|
| 基本威力増加 / 最終威力増加 | 効く | 効く |
| コイン威力増加 | 効く | 効く(コイン枚数ぶん効くので、多コインほど伸びる) |
| マッチ威力増加 | 効く | 効かない |

- 攻撃加重値が2以上のスキルは複数の敵を同時に攻撃する(広域攻撃。サブターゲットは自動選択)。

## 4. マッチ

- 攻撃スキル同士がぶつかると **マッチ**。勝った側だけが攻撃し、負けた側のスキルは取り消される。**被弾はマッチに勝って防ぐのが基本**(回復手段が乏しいゲーム)。
- 進行: 双方が全コインを投げる → 威力を比べ、低い側のコインを1枚破壊 → どちらかのコインが尽きるまで繰り返す → 勝者は **残ったコインだけで** 攻撃。
  - 途中で破壊されたコインの効果(例: Ⅰコインの的中時効果)は発動しない。
  - コインが多いスキルは試行回数が多いぶん粘れるが、相手のコインを全部割るまで投げ続ける必要もある。
- **攻撃レベル差3ごとに、高い側のマッチ威力 +1**。推奨レベルから -5 程度がまともにマッチできる下限。
- マッチ前に有利/不利が予測表示される。不利なマッチは E.G.O か守備スキルで対処する。
- 麻痺: コイン威力を0にする。コインを1枚「投げるたび」に1減る(表が出たときではない)。

## 5. 一方攻撃・守備スキル

- マッチせずに攻撃スキルを通すのが **一方攻撃**。コインを1枚ずつ投げ、コインごとにダメージ判定。威力補正(攻撃威力増加など)は1枚目にだけ乗り、以降は前の最終威力を基準に積み上がる。

| 守備 | 発動 | 性質 |
|---|---|---|
| ガード(防御) | 対象スキルの攻撃前 | 威力分のバリア(そのターンだけの追加体力)。確実に軽減するが的中時効果は受ける |
| 回避 | 相手のコインごと | 回避威力 ≧ 攻撃威力ならそのコインを無効化(ダメージも的中時効果も無し)。成功し続ける限り、同ターンの後続の攻撃にも再使用される。精神力の影響大 |
| 反撃 | ターン中最初に攻撃を受けた直後 | 攻撃はそのまま受け、その後防げない一方攻撃を返す。反撃前に混乱・死亡すると不発。出血が発動しない |
| マッチ可能ガード / 反撃 | 一方攻撃を受けたとき | 攻撃スキルのようにマッチする。勝てば相手のスキルを取り消せるが、負けたときの性能は通常の守備より劣る。マッチ可能ガードは必ず破壊不能コインを持つ |

- 守備スキル同士は **相殺**(どちらも発動しない)。ただし反撃は相殺されない。
- 属性を持たない守備スキルは資源も共鳴も得られない。防御・回避に罪悪属性が付くのは同期Ⅳから(反撃は最初から)。

## 6. ダメージと耐性

- ダメージは概ね **スキル威力 × 耐性倍率**。耐性は **攻撃タイプ(斬撃/貫通/打撃)** と **罪悪属性(7種)** の両方を掛け合わせる。
  - 倍率の目安: 耐性 ×0.5 / 抵抗 ×0.75 / 普通 ×1.0 / 脆弱 ×2.0(混乱中はさらに悪化)。
  - 属性はダメージにだけ効き、マッチには影響しない(じゃんけんではない)。
- **物理(攻撃タイプ)耐性は人格ごと**(データの `statuses[].resistance`)。
- **罪悪耐性は E.G.O で決まる**: 戦闘開始時は装備中の ZAYIN E.G.O の耐性。別の E.G.O を使うとその E.G.O の耐性に上書きされる。
- 大ダメージを受けるのはほぼ「脆弱で殴られたとき」。受け手を選ぶのが重要。

## 7. 速度と行動順

- 速度が高い順に行動する。人格の速度は範囲(例 3-7)で、毎ターン振り直す。
- 集中戦闘では、**敵より速い囚人は、自分が狙われていなくてもその敵のスキルとマッチできる**。同速以下だと狙われた囚人しかマッチできず、一方攻撃を受ける。
- 混乱した敵は行動しない。マッチで勝てない大技は、最も遅い囚人にマッチを担当させ、速い囚人の一方攻撃で先に混乱・撃破させる手もある。

## 8. 精神力・パニック

- 精神力は -45〜+45。開始時は 0。人格ごとに増減条件が違うが、おおむね「マッチ勝利・敵撃破で上昇、味方死亡・E.G.O使用で低下」。
- 味方が -45 に達すると、初期 E.G.O のみ装備なら **パニック**(1ターン行動不能・被ダメージ増加)、それ以外の E.G.O 装備中なら **E.G.O侵蝕**(侵蝕スキルを強制使用。敵味方を問わず攻撃することが多い)。1ターン後に精神力0へ戻る。
- 敵は -20 以下で士気低下、-45 でパニック(内容は敵ごと)。精神力を持たない敵もいる。

## 9. 混乱(スタッガー)

- 体力バー上の **混乱区間** までダメージを受けると、1ターン行動不能 + 全ダメージに脆弱。段階は 混乱 ×2.0 / 混乱+ ×2.5 / 混乱++ ×3.0。
- 一度踏んだ混乱区間は消える。ボス戦は「混乱区間まで削る → 混乱中に大ダメージ」が基本。
- データの `混乱区間`(例 `70%/40%/20%`)は区間の位置。区間が多い/高い位置にある人格ほど混乱しやすい。
- 振動は混乱区間を前に押し出す(混乱を早める)。

## 10. 罪悪資源・共鳴・パッシブ

- 罪悪属性つきのスキル(攻撃・守備・E.G.O)を使うと、その属性の **資源** が1つ溜まる。資源は E.G.O の使用でのみ消費する。
- **共鳴**: そのターンにパネル上で同じ罪悪属性のスキルを複数使うこと。隣接して3つ以上並べると **完全共鳴**。共鳴・完全共鳴は攻撃/防御レベルを上げる(完全共鳴3〜4で +3〜+5、つまりマッチ威力 +1 前後)。
- 人格パッシブの発動条件は2種類:
  - **保有**: 指定属性の資源を一定数持っている(データの `condition: "保有"`、`resource: "傲慢×4"` など)
  - **共鳴**: そのターンに指定属性のスキルを一定数使った(`condition: "共鳴"`)
- **バトルパッシブ** は出撃中の人格だけ、**サポートパッシブ** は出撃していない人格だけが発動する(同時には発動しない)。
- ガイドで見る観点: その人格のスキルの罪悪属性は何か(= どの資源を供給できるか、どのパッシブ・E.G.Oを支えられるか)。

## 11. 主要な状態効果(7種)

どれも **効果威力** と **回数** を持ち、だいたい回数が尽きるまで威力ぶん働く。威力と回数の両方を伸ばすと掛け算的に強くなる。

| 効果 | 種類 | 動き |
|---|---|---|
| 火傷 | 敵へ | ターン終了時に威力分の固定ダメージ、回数-1。立ち上がりが早く維持が簡単 |
| 出血 | 敵へ | **攻撃スキル** のコインを投げるたびに威力分のダメージ、回数-1。守備スキルでは発動しない。マッチ中も投げるたびに発動 |
| 振動 | 敵へ | 単体では何もしない。「振動爆発」を受けたとき威力分だけ混乱区間を前進させる |
| 破裂 | 敵へ | 攻撃が的中するたびに威力分の追加ダメージ、回数-1。多コインの攻撃と相性が良い |
| 沈潜 | 敵へ | 的中のたびに精神力ダメージ。精神力の無い敵には憂鬱属性ダメージ(相手の憂鬱耐性が効く) |
| 呼吸 | 自分へ | 的中時に (威力×5)% でクリティカル(ダメージ+20%)。威力20で確率100% |
| 充電 | 自分へ | 回数を最大20まで溜め、スキルで消費して強い効果を出す |

- 用語の正確な定義は人格データの `keywords[].desc`(wiki のツールチップ)を使う。
- 8章以降、「火傷・出血・振動・破裂・沈潜による被ダメージ -○%」を持つボスが増えている。

## 12. 破壊不能コイン

- マッチで負けても **割れない** コイン。マッチに勝っても、破壊不能コインが残っていれば **こちらの攻撃 → 相手の攻撃** の順で殴られる。
- マッチで破壊判定を受けた破壊不能コインはコイン威力が1になる(後から乗るコイン威力増加は有効)。だから破壊不能コインにも **マッチ勝利が最善**。
- 対処: 攻撃威力減少・麻痺・バリアで被害を減らす / 回避する(ただしマッチ勝利前提のギミックには対応できない)/ 弱点を突かれない・硬い人格で受ける / 先に混乱・撃破する / マッチ勝利後に同じスロットへ置いたガード・回避で受ける(裏置き)。
- 味方の破壊不能コインはシーズン5以降の人格・E.G.Oにある。データでは `unbreakableCoins`(元から)と `unbreakableByEffect`(スキル効果で変化)、パッシブの `unbreakableByEffect` で区別。

## 13. 編成・育成

- 編成順(選んだ順)が若いほど、ターン経過で **スロット(行動回数)** が先に増える。パッシブの対象選択の同率決着も編成順。主力を先頭に。
- 少人数出撃は主力の行動回数を増やせる強力な戦術。ただし7章以降の連続戦闘では死亡者が出ると立て直しが難しい。
- 育成は人格のレベル(体力・攻撃/防御レベル)・同期化(Ⅱでパッシブ、Ⅲで S3。Ⅲが基本性能)・E.G.O の解析。
- **キーワード編成**: 状態効果を1つに絞って特化させると、威力×回数の積み上げで爆発的な火力になる。マイナス効果(火傷・出血・振動・破裂・沈潜)の特化は単体のボス戦で本領を発揮し、プラス効果(呼吸・充電)は複数の敵にも効きやすく通常戦闘向き。

## 14. 人格を評価するときの観点

ガイドを書くときは、次の観点で根拠となるデータを拾う。

1. **マッチ力**: 各スキルのマッチ威力(範囲)・コイン枚数・攻撃レベル補正(`スキルレベル`)。減算コインの有無。
2. **火力**: 攻撃タイプ・罪悪属性、多コインか、状態効果との噛み合い、攻撃加重値(広域か)。
3. **耐久**: HP、物理耐性(弱点の数)、守備スキルの種類と威力、守備Lv、混乱区間の位置。
4. **速度**: 速度範囲。速いほどマッチを取りに行ける。
5. **資源**: スキルの罪悪属性構成(何の資源を出し、何の共鳴に参加できるか)。パッシブの必要資源とそれを自分や味方が満たせるか。
6. **キーワード**: 付与する/参照する状態効果(`keywords`)。同じキーワードを扱う人格との相性。
7. **特殊ギミック**: 変化スキル(`special`)、破壊不能コイン、独自のカウンター(データの `keywords` に定義がある固有用語)。
